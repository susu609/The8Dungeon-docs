# File save tiến trình

**Trạng thái:** chưa bắt đầu

**Mục tiêu:** lưu tiến trình và thành tựu xuyên các lần chơi (kiểu Isaac / Slay the Spire), mở khóa nội dung. Khó đọc/sửa, gắn với tài khoản Minecraft bản quyền.

**Câu hỏi cần chốt:** lưu ở client hay server? Lưu những gì? Mức bảo vệ chấp nhận được?
